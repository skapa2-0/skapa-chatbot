Présentation

Kosette.ia transforme votre site en assistant conversationnel. Il lit vos pages, répond à vos visiteurs dans leur langue et donne le lien de la page d'où vient chaque réponse.

ℹ️
Vous voulez essayer tout de suite ? Collez l'adresse de votre site sur la page d'accueil.
Créer votre assistantAnalyser votre site en un clic. Installer le widgetUne ligne de code sur votre site.

Démarrer

Créer votre assistant

Fonctionne pour tous les sites : boutique, agence, école, SaaS, restaurant.

  1. Collez votre adresse

    Sur la page d'accueil, entrez l'adresse de votre site, par exemple https://mon-site.fr, puis cliquez sur Analyser et adapter.

  2. Laissez Kosette lire votre site

    Le nombre de pages lues s'affiche pendant l'analyse.

  3. Testez votre assistant

    Quand l'analyse est terminée, la bulle de chat apparaît en bas à droite. Posez-lui une question.

Ce que votre assistant apprend

  • Les pages publiques de votre site : accueil, services, tarifs, contact, FAQ.
  • Les documents PDF ajoutés à sa base.
💡
Si une information n'est pas sur votre site, l'assistant le dit au lieu d'inventer.

Installer le widget

Une ligne de code, collée juste avant </body>.

<script
  src="https://chat.skapa.design/skapa-widget.js"
  data-api-url="https://chat.skapa.design"
  data-site-url="https://mon-site.fr"
  data-title="Assistant"
  data-color="#5b3fd4"
  async></script>
AttributRôle
data-api-urlAdresse du serveur de l'assistant.
data-site-urlLe site dont l'assistant doit parler (déjà analysé).
data-titleNom affiché en haut du chat.
data-colorCouleur principale du widget.

Autre option : une iframe

À utiliser si votre site n'accepte pas les scripts tiers, ou pour afficher le chat toujours ouvert au milieu d'une page (Contact, FAQ).

<iframe
  src="https://chat.skapa.design/embed.html?site=https://mon-site.fr&title=Assistant&color=%235b3fd4"
  title="Assistant"
  loading="lazy"
  style="width:100%;max-width:420px;height:600px;border:0;border-radius:16px"
></iframe>
ParamètreRôle
siteURL complète du site dont l'assistant doit parler (déjà analysé).
titleNom affiché en haut du chat (60 caractères max, « Assistant » par défaut).
colorCouleur principale, au format hexadécimal. Le # s'écrit %23 dans une URL.
💡
Le script affiche une bulle flottante en bas à droite de la page. L'iframe affiche le chat toujours ouvert à l'endroit où vous la placez.

Langues des visiteurs

L'assistant répond dans la langue de la question, même si votre site est en français.

  • La langue est détectée à chaque message : français, anglais, espagnol, allemand, italien, portugais.
  • Pour un message trop court (« ok », « merci »), il garde la langue du message précédent.

Intégrations

WordPress, Shopify, Wix…

Partout, le principe est le même : coller le script dans le pied de page.

  • WordPress / WooCommerce : avec un module d'insertion d'en-tête et pied de page.
  • Shopify : Thèmes → Modifier le code → theme.liquid, avant </body>.
  • Wix / Squarespace : Paramètres → Code personnalisé, sur toutes les pages.

Ce qui arrive

Ces fonctions sont en préparation.

  • Comptes et abonnements : création de compte et paiement en ligne.
  • Tableau de bord : conversations, contacts collectés, statistiques.
  • Personnalisation : nom, couleur, message d'accueil de l'assistant.
  • Actions : transfert à un humain, collecte de contacts, prise de rendez-vous.
